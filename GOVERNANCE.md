# Project governance

LipoScope software releases are versioned. Changes affecting literature retrieval, classification, CCRF source files, schema generation, validation, branching, completion or export behaviour require documentation and automated tests.

Official CCRF content remains attributed to the Lipedema Foundation and is not relicensed by LipoScope. LipoScope-specific interface and software changes must not be presented as alterations to the official CCRF source definitions.
