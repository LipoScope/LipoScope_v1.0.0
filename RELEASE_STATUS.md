# LipoScope v1.0.0 release status

This package contains the complete LipoScope browser application, CCRF Version 1 source-to-schema workflow, frozen source records, automated tests and generated validation reports.

The CCRF implementation is intended for de-identified browser-local research planning, collection review and export. It is not an institutionally governed REDCap deployment, does not store direct identifiers, files or signatures, and does not diagnose a patient.
