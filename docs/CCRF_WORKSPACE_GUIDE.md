# CCRF Research Workspace

The CCRF Workspace contains three connected modules that use the same selected classification, schema and active browser-local record.

## Standardized Cohort Builder

Select Core, Supplemental Highly Recommended, Supplemental or Exploratory. Navigate by official form and section. Conditional fields appear only when their official branching expression evaluates as applicable. Required-field completion is calculated from currently applicable, locally assessable response fields rather than from all published CDEs.

## Cohort Design Gap Radar

The Gap Radar reports missing or invalid applicable required responses, direct identifiers excluded from local storage, retained values in inactive branches and saved records whose schema version or source checksum differs from the current embedded schema.

## CCRF Data Dictionary and Dataset Export

The dictionary view shows source variables, labels, choices, validation, branching and active-record responses. Exports include coded data, readable labels, combined codes and labels, long-format values, the data dictionary, a data-quality report and a source manifest.

## Privacy and calculated fields

Direct identifiers, signatures and uploaded files are not stored as CCRF record values. Calculated fields are displayed as unavailable when the official source dictionary does not contain an executable calculation expression; LipoScope does not substitute a conventional formula.
