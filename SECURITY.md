# Security and privacy

LipoScope is a static browser application. It has no application backend and does not require an account.

## Browser-local information

The following may be stored in the current browser:

- Browse visibility and user-added paper settings;
- local notes;
- optional local profile label;
- CCRF research records using study identifiers;
- local PDF preview data where browser storage permits.

## CCRF privacy boundary

Fields marked as direct identifiers in the official CCRF source are not collected into browser-local records or exported by LipoScope. Uploaded files and signatures are not persisted as CCRF values. Researchers requiring complete identifiable capture should use an institutionally governed system.

Do not commit credentials, participant identifiers, private clinical data or restricted publication content to the public software package.
